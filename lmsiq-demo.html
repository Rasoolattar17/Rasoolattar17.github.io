How LmsIQ works

Write YAML, not code. LmsIQ handles the rest.

YAML test scenarios
QA testers write simple YAML files. No Playwright, no TypeScript, no code.
Moodle-aware actions
loginAs, openCourse, completeScorm, verifyActivityCompleted — built for Moodle.
Semantic recorder
Record your workflow once. LmsIQ generates the YAML automatically.
Full failure evidence
Screenshot, video, and trace on every failure. Know exactly what broke and why.
